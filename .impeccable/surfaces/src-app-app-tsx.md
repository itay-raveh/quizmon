Quizmon preserves its recognizable wordmark and crisp Pokémon-game landscape. The landing screen keeps its familiar open composition and uses the approved restrained Logo Echo treatment: one large cobalt Daily Challenge button is the primary action, while Settings, Trainer Card, and Start training remain smaller beneath it. The daily control contains its date without an outer card or nested button. After completion, the same footprint becomes a cream share button that shows the score. Once all eight League Badges are earned, one centered cream Quizmon League action appears below the compact control row as a clearly secondary destination.

Quiz states, results, Settings, and the Trainer profile belong to the same small game system without becoming a simulated handheld console. Card, Badges, and Titles form one compact three-way profile control. Functional interface icons use one bold, rounded Phosphor family. Social-network logos and game artwork remain intentional exceptions. The Badge Case is a cool metal shell with a dark inset tray and eight unlabeled badge recesses, not a loose grid of achievement cards. Trainer Titles use one warm wood display board with brass fasteners, a current-title plaque, and eight icon-led progress plaques. Selecting any title opens its description and progress; earned titles are equipped from that detail view. The collection remains visually continuous rather than becoming a dashboard of floating cards.

The unlocked Badge Case adds a ruled League gateway with only its name, the exact 15-answer requirement, five square stage markers, and one start or rematch action. The active League question uses a compact I, II, III, IV, C progress rail and the current trial name. A failed run reports the reached trial and retry action. A perfect run reports Champion and links directly to the Hall of Fame Badge Case. Result progress routes badge changes to the case and title-only changes to Trainer Titles. These states use mechanical copy only, never slogans or advertising language.

Controls borrow the wordmark's navy outline, cobalt fill, warm yellow lower edge, compact corners, and modest hard shadow. Collection structure comes from shared frames, dividers, and aligned compartments. Avoid giant HUD frames, pixel fonts, glass panels, gradients, blurred scenery, campaign-style copy, generic stat dashboards, nested floating cards, and broad structural changes. Motion is quick and physical through transform and opacity. The first viewport must preserve the approved open composition before responsive adaptation.
